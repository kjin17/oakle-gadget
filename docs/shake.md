# 흔들기 반응

대기 중에 기기를 흔들면 오클이 어지러워한다. 네트워크 없이 기기 안에서만 돈다.

## 쓰는 법

- 대기 화면(READY, 답 자막이 남아 있는 화면, 어두워진 화면 모두)에서 기기를 **빠르게 왕복 두세 번** 흔든다. 「흔들흔들흔」, 1초 남짓이면 된다.
- 반응: **어지러운 표정**(`mindblown`, 도형 얼굴이면 X 눈)이 좌우로 흔들리면서 **「띠요요용」** 내려가는 떨림 소리가 0.6초 난다. 그 뒤 1초 멈췄다가 원래 표정으로 돌아간다. 화면이 어두웠으면 밝아지고, 졸린 얼굴이었으면 기본 얼굴(`joy`)로 돌아간다.
- 반응 중에 버튼을 누르면 바로 그친다. 그 누름은 그대로 녹음 등으로 이어진다.
- 한 번 반응하면 **5초** 동안은 다시 흔들어도 반응하지 않는다.
- 소리는 기기 안에서 만든다(`M5.Speaker.tone`). 네트워크는 쓰지 않는다. 볼륨은 답 재생과 같다(USB 255 / 배터리 185).
- 시리얼에 한 줄 남는다: `shake: peaks=5 max=3.1g dur=520ms face=mindblown was_dim=0`. 부팅 때는 `boot: imu=ok type=6 shake=on thr=1.8g peaks=5 gap=400ms cool=5s`(`type=6` = BMI270).

## 안 세는 때

- 녹음·재생·Wi-Fi 설정 모드·IR 학습 중에는 세지 않는다. 이 동작들은 loop 를 막고 돌기 때문에 그동안 샘플이 안 들어온다. 샘플 사이가 0.2초를 넘으면 처음부터 다시 센다.
- 버튼을 누르고 있을 때, 손댄 직후 0.4초 안, 스피커가 울리는 중에도 세지 않는다.

## 조절값 (`config.h` 에서 덮어쓴다)

| 상수 | 기본 | 뜻 |
|---|---|---|
| `SHAKE_ENABLE` | 1 | 0 이면 끈다 |
| `SHAKE_G` | 1.8 | 봉우리 문턱. 중력을 뺀 가속도 크기(g). 오작동하면 올리고, 잘 안 먹으면 내린다 |
| `SHAKE_PEAKS` | 5 | 방향이 번갈아 바뀐 봉우리 수. 5 = 왕복 두 번 반 |
| `SHAKE_WINDOW_MS` | 1500 | 봉우리들이 이 시간 안에 들어와야 한다 |
| `SHAKE_GAP_MS` | 400 | 봉우리 사이 최대 간격. 1 Hz 남짓으로 느리게 흔들면 안 센다 |
| `SHAKE_COOLDOWN_S` | 5 | 반응 뒤 쉬는 시간 |
| `FACE_DIZZY` | `"mindblown"` | 반응 표정 이름(20종 중 하나) |

## 하드웨어

IMU 는 **BMI270**, 내부 I2C(SDA G47 / SCL G48) 주소 **0x68** 이다. 인터럽트 선은 ESP 가 아니라 M5PM1 G4 에 붙어 있다 [근거: docs.m5stack.com/en/core/StickS3 PinMap, 회로도 V0.6 `PYG4_IMU_INT`]. 그래서 인터럽트는 쓰지 않고 `M5.Imu.getAccel()` 을 loop(약 100 Hz)에서 읽는다. M5Unified 0.2.26 은 BMI270 의 ACC_CONF·ACC_RANGE 를 건드리지 않는다. 그래서 칩 기본값인 **±8 g·100 Hz** 로 돈다 [근거: `BMI270_Class.inl` 의 `aRes = 8/32768`, ACC_CONF 쓰기 없음]. 축 방향은 M5Unified 가 StickS3 용으로 맞춘다. 감지는 방향을 가리지 않으므로 축 방향과는 상관없다.

## 감지 방식 (`firmware/oakle_gadget/shake_detect.h`)

1. 저역 통과(시정수 250 ms)로 중력을 추정해서 뺀다. 남은 「움직임 가속도」의 크기를 본다.
2. 크기가 `SHAKE_G` 를 넘으면 봉우리가 시작된다. `SHAKE_G/2` 아래로 내려오거나, 문턱 위에서 방향이 120° 넘게 꺾이면 봉우리가 끝난다. 꺾임으로도 끝내는 이유가 있다. 세게 흔들면 ±8 g 에 포화돼 0 근처를 지나는 샘플이 없다. 시험이 이 경우를 잡았다.
3. 직전 봉우리와 **방향이 반대**이고 간격이 60~400 ms 이면 사슬을 잇는다. 아니면 새 사슬을 시작한다. 60 ms 아래는 같은 충격의 잔떨림으로 보고 버린다.
4. 사슬이 `SHAKE_PEAKS` 개가 되면 반응한다. 그 뒤 `SHAKE_COOLDOWN_S` 동안 쉰다.

거르는 원리는 이렇다. 걷기(손)는 0.3~0.6 g 라 문턱에 못 미친다. 주머니 걷기의 디딤 충격은 한쪽 방향이고 간격도 약 500 ms 라 400 ms 에 걸린다. 버튼 누름·탁 내려놓기는 봉우리가 1~2개뿐이다. 같은 방향으로 톡톡 치는 건 방향 반전이 아니다.

## 실기에서 확인할 것

- **문턱이 손에 맞는지가 가장 크다.** 합성 샘플의 크기는 [추론]이다. 실제로 흔들 때 `shake:` 줄의 `max=` 값을 보고, 걷거나 주머니에 넣고 다닐 때 반응이 없는지 본다.
- 뛰기·계단 뛰어 내려가기는 시험에 1.2 g 만 넣었다. 주머니에서 뛰면 2 g 를 넘을 수 있어 오작동할 여지가 있다 [추론].
- 배터리일 때 `tone` 소리 크기와 재부팅 여부를 본다.
- 반응하는 1.6초 동안 B 짧게(자막 넘기기)는 먹지 않는다. A·B 를 누르면 반응이 바로 그친다.
