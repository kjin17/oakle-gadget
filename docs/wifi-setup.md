# Wi-Fi 설정 모드

`config.h` 를 다시 굽지 않고도 휴대폰으로 Wi-Fi 를 넣고 바꾼다(캡티브 포털).

## 쓰는 법

### 처음 켤 때

1. 저장된 Wi-Fi 가 없거나(`config.h` 를 예시 그대로 구운 경우 포함) 부팅 때 저장 망에 하나도 못 붙으면 **설정 모드**가 된다. 화면에 `SETUP`, 「Wi-Fi 설정 모드」, AP 이름 `Oakle-Gadget-XXXX`(MAC 주소 끝 4자리), `192.168.4.1` 이 나온다.
2. 휴대폰 Wi-Fi 목록에서 `Oakle-Gadget-XXXX` 에 붙는다(기본은 비밀번호 없음). 설정 페이지가 저절로 뜬다. 안 뜨면 브라우저로 `http://192.168.4.1` 을 연다.
3. 「주변 Wi-Fi」에서 망을 누르고 비밀번호를 넣는다. 바깥 경로가 있는 펌웨어면(`RELAY_SECRET` 이 있는 경우) **「집 Wi-Fi」** 칸이 보인다. 집 공유기면 체크하고, 휴대폰 핫스팟이나 카페 Wi-Fi 면 체크하지 않는다.
4. 「저장하고 다시 켜기」를 누르면 NVS 에 저장한 뒤 2초 뒤 재부팅해서 붙는다. 비밀번호가 틀려 못 붙으면 설정 Wi-Fi 가 다시 뜬다.

숨은 SSID 는 목록에 안 나오므로 이름 칸에 직접 적는다.

### 망을 더하거나 바꿀 때

- **A+B 를 함께 5초** 누른다. 화면에 남은 초가 나오고, 5초가 되면 설정 모드가 된다. 그 전에 하나라도 떼면 아무 일도 없다. 녹음 중에 B 를 누르면 그 녹음은 버리고 조합으로 센다.
- 또는 **B 를 누른 채 켠다**(전원을 넣거나 리셋하고 B 를 2초 더 누르고 있는다). B 를 짧게 눌러 잠에서 깨운 것은 해당하지 않는다.
- 최대 **5개**까지 저장한다. 같은 이름을 다시 저장하면 고친다. 비밀번호 칸을 비우면 예전 비밀번호를 그대로 두고 「집」 표시만 바꾼다. 다 찼으면 저장을 거절한다. 하나를 지워야 새로 넣을 수 있고, 자동으로 빠지는 망은 없다.
- 설정 모드에서 **A** 를 누르면 저장 없이 나와 평소대로 붙는다. 휴대폰이 안 붙은 채 3분(`PORTAL_TIMEOUT_S`)이 지나도 나온다. 저장 망이 하나도 없으면 시간이 지나도 나오지 않는다. 대신 배터리로 돌고 있으면 5분 뒤 평소처럼 잠든다.

### 초기화(저장 망 모두 지우기)

- 설정 페이지 맨 아래 **「모두 지우기」**를 누른다. 확인 창이 뜬다. 하나씩 지울 때는 망마다 「지우기」를 누른다.
- 휴대폰 없이 할 때는 설정 모드에서 **B 를 5초** 누른다. 설정 모드에 들어올 때 누르고 있던 B 는 한 번 뗀 뒤부터 센다. 그래서 A+B 5초로 들어오자마자 지워지는 일은 없다.
- 지운 뒤 재부팅하면 저장 망이 없으므로 설정 모드로 켜진다. `config.h` 의 Wi-Fi 값은 **다시 들어오지 않는다**(아래 「시드」 참고).

## 버튼 정리

| 누름 | 평소 | 설정 모드 |
|---|---|---|
| A 누르는 동안 | 녹음 → 질문 | — |
| A 짧게 | (재생 중이면 끊고 새로 녹음) | 나가기 |
| B 짧게(0.5초 안) | 답 자막 한 줄 내리기 | — |
| B 3초 | IR 학습 (A 를 같이 누르고 있으면 안 함) | — |
| B 5초 | — | 저장 망 모두 지우기 |
| A+B 5초 | 설정 모드 | — |
| B 누른 채 켜기(2초) | 설정 모드 | — |

## 집 모드/바깥 모드 판정 — 결정과 근거

**항목마다 「집」 표시 칸을 둔다.** 표시가 붙은 망에 붙으면 집 모드(LAN 의 voice_bridge, `SERVER_URL`), 아니면 바깥 모드(중계 서버, `RELAY_URL`)다.

- SSID 상수 두 개(`WIFI_SSID`=집, `HOTSPOT_SSID`=바깥)만으로는 포털로 새로 넣은 망이 어느 쪽인지 정할 수 없어서, 판정을 저장 항목에 둔다.
- 첫 부팅 때 `config.h` 의 `WIFI_SSID` 는 「집」으로, `HOTSPOT_SSID` 는 「바깥」으로 NVS 에 들어간다.
- `WIFI_SSID` 를 집 판정 기준으로 쓰는 안은 고르지 않았다. 그 안이면 집 공유기를 바꿀 때마다 다시 구워야 한다. 또 집이 둘인 경우(5G·2.4G 따로, 메시 SSID 둘)를 표현할 수 없다.
- 붙는 순서는 예전처럼 **집 먼저**다. 보이는 저장 망 중 집 표시 망을 먼저 시도하고, 같은 쪽끼리는 신호가 센 것부터 시도한다. `-DPREFER_OUTDOOR=1` 로 빌드하면 바깥이 먼저다(집에서 바깥 경로를 시험할 때).
- 펌웨어에 `RELAY_SECRET` 이 없으면 바깥 경로를 쓸 수 없으므로 **모든 망을 집 모드로 본다.** 이때 페이지에는 「집」 칸이 나오지 않는다. 바깥 경로가 있는지는 `HOTSPOT_SSID` 가 아니라 `RELAY_SECRET` 으로 정한다. 핫스팟 이름은 포털로도 넣을 수 있어서다.
- 판정은 SSID 하나만 본다. 같은 이름의 망이 다른 곳에 있으면(예: 흔한 기본 SSID) 그 망도 같은 쪽으로 간다.

## 시드(`config.h` 값)와 NVS

- NVS 이름공간 `wifi`: `n`(개수), `s0..s4`(SSID), `p0..p4`(비밀번호), `h0..h4`(집), `seed`(시드 지문).
- `config.h` 의 `WIFI_SSID/WIFI_PASS`(집)와 `HOTSPOT_SSID/HOTSPOT_PASS`(바깥)는 **첫 시드로만** 쓴다. 그 뒤로는 NVS 가 우선한다. `"CHANGE_ME"` 와 빈 값은 건너뛴다. 그래서 예시 config 로 빌드해도 포털만으로 설정할 수 있다. Wi-Fi 상수를 아예 지워도 빌드된다.
- 시드 값의 지문(FNV-1a)을 `seed` 에 적어 둔다. **시드 값을 바꿔 다시 구웠을 때만** 다시 합친다. 같은 이름이 있으면 비밀번호와 집 표시를 덮어쓰고, 없으면 맨 앞에 넣는다. 그래서 포털에서 지운 시드 망은 재부팅해도 되살아나지 않는다. 「모두 지우기」도 지문은 남긴다.
- 비밀번호는 NVS 에 평문으로 저장된다(`config.h` 에 넣어 구울 때 바이너리에 평문으로 들어가는 것과 같은 수준). 설정 페이지에는 비밀번호를 싣지 않는다. 시리얼과 화면에도 SSID·비밀번호를 찍지 않는다(목록 번호와 경로만).

## 구현

- `firmware/oakle_gadget/wifi_list.h`: 목록(추가·고침·지우기), 붙는 순서, 시드 합치기, 설정 페이지 HTML. Arduino 없이 컴파일된다.
- `oakle_gadget.ino`: NVS 읽기·쓰기(`nets_load/nets_save/nets_seed_from_config`), 스캔(`wifi_scan`), `wifi_connect(allow_blind)`, `portal()`, `combo_hold()`.
- 라이브러리는 더하지 않았다. ESP32 코어에 들어 있는 `WebServer` 와 `DNSServer` 만 쓴다. DNS 는 모든 이름을 192.168.4.1 로 돌린다. 휴대폰의 연결 확인 요청(`/generate_204`, `/hotspot-detect.html` 등)은 처음 보는 경로이거나 Host 가 다르므로 `http://192.168.4.1/` 로 302 보낸다. 그러면 캡티브 포털 창이 뜬다 [추론: iOS·Android 의 일반 동작, 실기 미확인].
- 재연결: 저장 망이 하나도 안 보일 때 「전부 차례로 시도」(숨은 SSID 대비)는 **부팅 때만** 한다. 스캔 자체가 실패했을 때도 한다. 망이 5개면 다 시도하는 데 40초가 걸리고 그동안 버튼이 먹통이 되기 때문이다. 재연결 때는 보이는 저장 망만 시도한다.
- `PORTAL_PASS` 를 `config.h` 에 넣으면 설정 Wi-Fi 에 비밀번호가 걸린다(8자 이상). 기본은 열린 망이다. 설정 모드는 첫 부팅, 실패, 버튼으로 들어갈 때만 잠깐 열린다.
- 조절값: `PORTAL_TIMEOUT_S`(180), `PORTAL_COMBO_MS`(5000), `PORTAL_BOOT_HOLD_MS`(2000), `PORTAL_WIPE_MS`(5000), `WIFI_MAX_NETS`(5).

## 시험

- 호스트 시험(리포 루트): `c++ -std=c++17 -Wall -I firmware/oakle_gadget tools/test_wifi_list.cpp -o /tmp/t && /tmp/t /tmp/wifi_portal.html`
  한글 SSID 32바이트 경계, `'`·`"`·`<>` 가 섞인 이름의 이스케이프, 비밀번호 비노출, 꽉 참 거절, 집 먼저·신호 순서, PREFER_OUTDOOR, 시드 지문을 본다.
- 실기 확인 순서: ① `config.h` 에 집 Wi-Fi 를 넣어 굽고 시리얼에 `wifi: seed from config.h` 와 `boot: nets=1` 이 찍히는지 ② A+B 5초 → 휴대폰으로 `Oakle-Gadget-XXXX` 에 붙어 설정 창이 뜨는지, 핫스팟을 집 칸 체크 없이 저장한 뒤 핫스팟만 켠 곳에서 화면 맨 아래에 「바깥」이 나오는지 ③ 설정 모드에서 B 5초 → 모두 지우기 → 재부팅하면 설정 모드로 켜지는지.
- 캡티브 창이 저절로 뜨는 동작은 휴대폰 OS 마다 다를 수 있다 [추론].
